Kebijakan Privasi

Terakhir diperbarui: Oktober 2026

Ringkasan: Privasi Anda adalah Prioritas Kami

🔒 EZer adalah aplikasi yang mengutamakan privasi dan offline-first. Data keuangan Anda tersimpan terenkripsi di perangkat Anda dan hanya keluar dari perangkat jika Anda memakai fitur cloud opsional (pembacaan rekening koran dengan AI, cadangan cloud, atau berbagi rumah tangga). Kami tidak menjual data pribadi Anda.

  • Data keuangan inti disimpan di perangkat Anda
  • Tidak diperlukan akun atau login
  • Fitur cloud bersifat opsional: pembacaan dengan AI dan berbagi rumah tangga mengirim data ke server kami; cadangan cloud diunggah terenkripsi ke penyedia cloud Anda
  • Enkripsi AES-256 untuk data di perangkat Anda
  • Tidak ada pelacakan perilaku pengguna

1. Informasi yang Kami Kumpulkan

Data yang Tidak Kami Kumpulkan

EZer dirancang dengan privasi sebagai inti. Kami TIDAK mengumpulkan:

  • Data transaksi atau keuangan Anda (kecuali yang Anda kirim lewat fitur cloud opsional)
  • Informasi pribadi (nama, email, telepon), kecuali nama dan email dari Google atau Microsoft jika Anda masuk untuk cadangan cloud atau berbagi rumah tangga
  • Data lokasi
  • Kontak atau data SMS
  • Riwayat penelusuran atau penggunaan aplikasi lain

Data Analitik Anonim (Opsional)

Dengan izin Anda, kami dapat mengumpulkan data analitik anonim untuk meningkatkan aplikasi, seperti:

  • Jumlah pengguna aktif (tanpa identifikasi)
  • Fitur yang digunakan (tanpa konten)
  • Laporan crash untuk memperbaiki bug

2. Penyimpanan Data

Semua data keuangan Anda disimpan secara lokal di perangkat menggunakan SQLite dengan enkripsi SQLCipher (AES-256). Data ini hanya keluar dari perangkat jika Anda memakai fitur cloud opsional: pembacaan dengan AI dan berbagi rumah tangga mengirim data ke server kami, dan cadangan cloud diunggah terenkripsi ke penyedia cloud Anda.

💾 Data Anda ada di ponsel Anda, kecuali yang Anda kirim lewat fitur cloud opsional.

3. Izin Aplikasi

EZer hanya meminta izin yang diperlukan:

  • Kamera — Untuk scan struk (Plus). Foto tidak pernah diunggah.
  • Biometrik — Untuk kunci aplikasi dengan sidik jari atau Face ID.
  • Notifikasi — Untuk pengingat tagihan (opsional).

4. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau berbagi data pribadi Anda dengan pihak ketiga. Layanan pihak ketiga yang digunakan antara lain (penyedia untuk fitur cloud opsional dijelaskan di bagian pembacaan dengan AI dan transfer data di bawah):

  • Firebase Analytics — Hanya data anonim jika fitur analitik diaktifkan
  • Apple/Google — Untuk pemrosesan pembayaran in-app (Plus)

5. Keamanan Data

Langkah keamanan yang kami terapkan:

  • Enkripsi AES-256 untuk semua data di perangkat Anda
  • Kunci biometrik opsional
  • Data keuangan hanya dikirim lewat jaringan saat Anda memakai fitur cloud opsional, melalui koneksi terenkripsi
  • Fitur inti bekerja tanpa internet

6. Hak Anda

Anda memiliki kendali penuh atas data Anda:

  • Ekspor semua data kapan saja
  • Hapus semua data dari pengaturan aplikasi
  • Ajukan permintaan penghapusan data melalui email

Untuk permintaan penghapusan data: support@ezerapp.com

Laporan Kerusakan

Kami mengumpulkan laporan kerusakan anonim dan log kesalahan non-fatal berdasarkan kepentingan sah kami dalam menjaga aplikasi tetap stabil (GDPR Pasal 6(1)(f); dasar hukum setara di bawah DPDPA dan kerangka kerja serupa). Laporan mencakup jejak tumpukan, model perangkat, versi sistem operasi, versi aplikasi, dan perkiraan wilayah (berasal dari IP; IP itu sendiri tidak disimpan). Kami tidak pernah menyertakan transaksi, saldo, nama, atau informasi pribadi lainnya. Anda dapat menonaktifkan pelaporan kerusakan kapan saja di Pengaturan → Privasi → Laporan Kerusakan.

Pembacaan Rekening Koran dengan AI (EZer Plus, opsional)

Pembacaan dengan AI mengubah rekening koran bank atau tagihan kartu kredit yang Anda pilih (PDF, gambar, atau CSV) menjadi transaksi. Fitur ini nonaktif sampai Anda memberikan persetujuan di aplikasi, dan Anda dapat menarik persetujuan kapan saja di Pengaturan → Dasbor Privasi. Semua fitur lain tetap berfungsi tanpanya.

Aplikasi mengirim dokumen ke server kami, yang mengirim isinya, beserta kode negara dan mata uang, jenis dokumen, dan nama kategori Anda, ke penyedia AI kami: Anthropic (Claude), di Amerika Serikat. Nama, email, dan ID akun Anda tidak dikirim ke Anthropic, dan tidak ada penyedia AI lain yang menerima dokumen Anda. Anthropic dapat menyimpan apa yang diterimanya untuk jangka waktu terbatas (misalnya hingga 30 hari) untuk pemantauan penyalahgunaan.

File dokumen tidak disimpan di server kami. Hasil pembacaan disimpan di basis data kami, terhubung ke akun Anda, agar dokumen yang sama tidak dibaca dan ditagih lagi; Anda dapat menonaktifkannya di Pengaturan → Keamanan, dan "Hapus Semua Data" menghapusnya.

Berbagi Rumah Tangga (EZer Plus, opsional, Android)

Di aplikasi Android, hingga 6 orang dapat berbagi transaksi, anggaran, tujuan, dan tagihan, membagi biaya, dan menyelesaikan utang sebagai satu rumah tangga. Setiap anggota memerlukan EZer Plus dan harus masuk dengan Google atau Microsoft, dan Anda hanya bergabung melalui undangan dari anggota. Setelah bergabung, apa yang Anda catat dibagikan ke rumah tangga secara default; di Pengaturan → Rumah Tangga Anda dapat mengecualikan kategori, menyembunyikan akun, atau berhenti membagikan item tertentu. Hanya anggota lain di rumah tangga Anda yang melihat item yang Anda bagikan.

Item yang dibagikan dienkripsi end-to-end: jumlah, deskripsi, merchant, catatan, kategori, dan detail lainnya dienkripsi di ponsel Anda (AES-256-GCM) dengan kunci rumah tangga yang tidak pernah sampai ke server kami dalam bentuk yang dapat dibaca, sehingga kami tidak dapat membacanya. Untuk menjalankan rumah tangga, server kami menyimpan nama rumah tangga, nama, peran, dan ID akun setiap anggota, serta tanggal, jenis, dan status setiap item yang dibagikan, di Google Cloud Firestore di India (Mumbai, asia-south1); fungsi server rumah tangga berjalan di region yang sama. Saat keluar, Anda dapat menghapus item yang Anda bagikan; pemilik dapat menghapus rumah tangga; dan "Hapus Semua Data" menghapus item yang Anda bagikan dan rumah tangga mana pun milik Anda.

Transfer Data Internasional

Data di server kami diproses oleh Google Cloud (Firebase). Basis data kami berada di India (Mumbai, asia-south1). Fungsi berbagi rumah tangga berjalan di India (asia-south1); fungsi pembacaan dengan AI, langganan, dan pembelian berjalan di Amerika Serikat (us-central1). Pembacaan dengan AI juga mengirim isi dokumen ke Anthropic di Amerika Serikat. Jika data Anda ditransfer ke luar negara Anda, kami mengandalkan Klausul Kontrak Standar Komisi Eropa (dan, bagi pengguna di Inggris, Adendum Transfer Data Internasional Inggris) yang termuat dalam Adendum Pemrosesan Data Google Cloud dan milik Anthropic. Anda dapat meminta salinannya di privacy@ezerapp.com.
